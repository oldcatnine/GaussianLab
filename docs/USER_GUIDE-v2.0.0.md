# GaussianLab V2.0.0 便携版使用说明

## 运行

适用目标为 Windows 10/11 x64，建议具备可用图形驱动；本版本在本机 Windows 11 x64 验证，其他电脑及全部显卡组合仍需实际复测。无需安装 Python、CUDA 或项目虚拟环境。

完整解压 GaussianLab-v2.0.0-Windows-x64.zip，进入文件夹并双击 GaussianLab.exe。必须保留 _internal 与其他随附文件，不要只复制 EXE，也不要直接在压缩包内运行。可以将整个文件夹复制到其他有写权限的位置运行。

窗口标题及 EXE 属性应显示 V2.0.0；界面为白色，右下有图像类型选择与“导出图片”。传播计算使用 CPU，修改参数后点击“计算光场”。本版不包含已撤回的 CUDA 和自动预览。

## 常用操作

1. 选择预置案例并点击“加载案例”；编辑源参数和透镜/光阑后点击“计算光场”。
2. 鼠标放在三维区域，用滚轮缩放、左键拖动旋转；“复位视角”恢复默认视角。
3. 移动观察屏，或点击“定位最小光斑”；右上切换光斑、剖面、强度曲面和包围能量。
4. 右下选择图像类型，再点击“导出图片”。支持六类图像与默认“当前分析图”；PNG 为 300 dpi，另支持 SVG/PDF，均为不透明白底。
5. 参数扫描需单独点击左侧“开始扫描”；收敛检查单独运行，不能替代扫描。
6. “保存项目”与“打开”处理 JSON；“导出 CSV”保存结果及对应参数快照。输入变化但尚未重算时，图和导出属于上次结果。

完整操作说明见 [当前版本指南](USER_GUIDE.md)，原理、教学练习与逐文件说明见 [离线学习手册](项目学习手册.html)。examples 附带三个预置项目。

## 文件与问题处理

程序使用有限窗口的近轴标量模型。采样、边界或焦点警告需按说明复核；高 dpi 图片不能提升计算精度。M²、高 NA、复杂像差和实体实验精度不在当前范围。

如无法启动，记录 Windows 版本、显卡型号、程序所在路径和错误信息。启动日志位于用户 LOCALAPPDATA 下 GaussianLab/logs/startup-error.txt。不要删除 _internal 中的动态库；如受组织设备策略限制，按该设备的正常软件管理流程处理。

本版未进行商业代码签名。Qt/PySide6 的完整许可与版权声明见 THIRD-PARTY-NOTICES.md 和 THIRD_PARTY_LICENSES。运行包、Qt 对应源码包、应用源码包及 SHA256SUMS.txt 应保持同一版本，第三方源码无需为运行而解压。
