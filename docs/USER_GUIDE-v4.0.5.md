# GaussianLab V4.0.5 使用指南

完整解压 `GaussianLab-v4.0.5-Windows-x64.zip`，保留同目录下的 `_internal`，双击 `GaussianLab.exe`。也可在源码目录运行项目环境的 `python -m gaussian_lab`。

1. 点击「完整计算」，在「结果分析 → A/B 对比」固定 A。修改光路后点击「计算 B 并比较」。单独完成扫描不会更新 B 的光场。
2. 选择共用观察面时，先用观察屏滑块定 z。若两方案在该处没有共同采样面，选取软件列出的实际位置和偏差，或取消。也可选择各自最小光斑面。
3. 对比页可切换光斑、剖面和包围能量，导出当前视图。并排光斑使用相同横纵范围及强度标尺。
4. 光路搭建、结果分析导出传播数据，参数扫描导出扫描表。扫描表区分成功、警告和失败，注明最小值是否位于搜索边界。
5. 指标卡显示快速预览或完整计算。运行多指标收敛后，点击「查看结果」检查焦区和末端 r86、位置、透过率、远场角及剖面变化。每次检查保存独立 JSON。
6. 打开项目后，光源和传播输入的显示会取整，计算与保存沿用原值，直至编辑该字段。超出允许范围的项目会提示具体字段。

更多操作见 [完整指南](USER_GUIDE.md) 和 [离线手册](项目学习手册.html)。
