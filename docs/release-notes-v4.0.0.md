# GaussianLab V4.0.0 · 第四代

2026-11-23。将截至源码 70699b1 的已实现能力汇总为第四代，统一应用与 Windows 文件版本为 4.0.0。

- 保留多薄透镜、有限口径、光阑菲涅耳衍射、轴向与参数扫描、A/B 光路对比和 CPU/CUDA 后端。
- TEM 双方向 0—3 阶、LG01—LG05 和 TEM01+TEM10 共 22 个模式预设，支持相干振幅与相位配置。
- 三维相干横截面与二维场对应；基模参考与实际光斑指标分别标示，仍为标量近轴模型。
- 提供内存估算、磁盘结果存储、2D/3D 模式、图像平滑及各图坐标范围设置。
- 纳入默认三维启动 CUDA 计算的线程回收闪退修复。
- 保留完整第三方许可、固定 CUDA 组件和首次头文件缓存校验；无兼容显卡时使用 CPU。

V3.2 工作台设计仍为规划，不作为已实现功能。新版本应完整解压，不能将旧 EXE 改名视为升级。

后续每次应用小更新递增 0.0.1：V4.0.0 → V4.0.1 → V4.0.2。历史版本和摘要不覆盖。

操作见 [第四代指南](USER_GUIDE-v4.0.0.md)，实际构建、测试与发布状态见 [验证记录](release-validation-v4.0.0.md)。
