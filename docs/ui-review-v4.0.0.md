# V4.0.0 界面易用性评审与改进建议

评审日期：2026-11-24。状态：设计建议，尚未实施。对象为已发布的 V4.0.0 Windows 程序；本次只记录评审，不改变应用版本。实际界面更新按补丁规则从 V4.0.1 开始。

## 观察依据

打开本机第四代 EXE，核对窗口标题，观察单透镜聚焦的启动预览；滚动完整左侧参数栏，切换尚未运行扫描的“参数扫描”页，最后恢复轴向传播及参数栏顶部。实际截图返回尺寸为 1522×1011，仅代表本次观察窗口，未做多分辨率或多人易用性实验。首次截图被前台其他窗口遮挡，提升目标窗口后才采用可辨认的 GaussianLab 图像。

结合 [界面源码](../gaussian_lab/gui.py)、[当前操作指南](USER_GUIDE.md) 核对控件顺序与导出逻辑。独立子代理进行了只读源码复核；导出行为结论来自源码，未在本次生成导出文件。

沿用 [既有界面调研](research.md) 和 [工作台提案](iteration-plan-v3.2.md) 中 Ray Optics Simulation 的元件选择、属性编辑与案例组织思路。本轮没有重新联网调查，也没有将旧提案视为已实现功能。

## 主要问题与建议

| 优先级 | 实际观察或代码依据 | 对操作的影响 | 建议 |
| --- | --- | --- | --- |
| P0 | 左栏依次排列光源、采样说明、计算与交互、横模、光路元件、扫描；首屏看不到透镜焦距 | 最常见的改焦距操作需要越过长篇内存、后端和模式设置 | 光源与光路元件置顶；默认展开当前选中元件。计算采样、性能与存储收进“高级设置” |
| P0 | 3D、二维光斑和下方图表常驻；上下有两组标签 | 不同任务争用屏幕，A/B 与纵向图尤其容易被压缩 | 按“光路搭建 / 结果分析 / 参数扫描”组织三种工作区，每次突出一项任务；光路页仍保留小型光斑预览 |
| P0 | 参数扫描页在尚未执行扫描时为空，启动按钮位于左栏下部 | 容易将空白理解为功能故障，用户需要跨区域寻找入口 | 扫描设置、运行按钮、曲线和数据放到同一工作区；空态明确显示“选择元件和范围，开始扫描”及可点击入口 |
| P0 | 左侧输入 N=1024，但启动图为 N=256 的快速预览；状态提示在底部，顶部卡片仍写“细化点” | 配置精度与当前显示结果的实际精度容易混淆 | 主按钮改为“完整计算”；在图和指标附近统一标记“预览 / 完整结果 / 参数已修改”；没有细化时不用“细化点”标签 |
| P1 | 内存估算多行、系统数值、缓存说明和刷新按钮占据较长区域；平滑显示位于计算设置中 | 阅读负担较大，显示选项远离所控制的图 | 状态栏显示简短资源摘要，点击展开详情；平滑、对数、坐标范围放到对应图的工具栏 |
| P1 | 元件表的同一“参数”列兼指焦距和光阑直径，横模表的 n/p、m/l 也需解释 | 新用户要先读说明再判断如何填写 | 列表展示元件摘要，选中后显示明确属性“焦距 f（mm）”“通光直径（mm）”；横模默认提供缩略图预设，点击“自定义叠加”才展开完整模式表 |
| P1 | “当前分析图”只根据右上四个分析标签选择导出；CSV 则根据底部标签决定是否导出扫描 | 同为“当前”，图片与数据的指代不同；看着底部扫描或 A/B 图时可能选错导出目标 | 每张图就地提供“导出此图”；表格旁提供“导出此数据”；全局导出菜单明确列出对象名称 |
| P1 | 场景中光路斜放、网格地面占据较多空间，叠加文字较多；四张指标卡始终占据顶部 | 三维主体与焦区不够突出，读数缺少主次 | 用紧凑导轨、较弱网格与更好的初始构图；增加总览/侧视/正看光斑；初始突出最小 r86、其位置及透过率，参考解与远场指标可展开 |

这些优先级是本次设计判断，尚未通过对照试用量化。需要保留全部专业参数的访问入口，避免把“精简首屏”理解为减少物理能力。

## 推荐的信息结构

| 工作区 | 常驻内容 | 按需展开 |
| --- | --- | --- |
| 光路搭建 | 左侧光源/透镜/光阑列表与选中属性；中央大幅 3D/2D 光路；右侧小型光斑预览；底部观察面滑块 | 自定义横模叠加、精细采样、内存和后端详情 |
| 结果分析 | 大幅光斑、剖面、能量或纵向图；共同观察面；关键指标 | A/B 对比、参考高斯解、远场、诊断细节 |
| 参数扫描 | 元件/参数/范围/点数、开始/取消、进度、曲线和数据 | 完整任务日志、失败点详情、扫描数据导出 |

全局顶部保留打开、保存、案例、完整计算与导出入口。取消只在任务进行中作为可执行动作；当前任务、结果时间与参数状态始终可见。首屏的常规路径应为“选择案例 → 点选透镜 → 修改焦距 → 查看预览/完整结果”，无需穿过内存与存储设置。

3D 主体保持视觉重点，同时保留横向放大倍率、示意几何和实际强度/包络区别。r86 首次出现配中文“86% 能量半径”，θ86 配“远场 86% 能量半角”；主界面用一句话提示，公式和完整定义在帮助中展开。

## 建议的实施顺序

1. 下一次小更新优先调整左侧顺序、折叠高级项、补扫描空态与入口、明确完整计算和结果状态。应用版本建议为 V4.0.1，实际实施后才递增。
2. 后续小更新再拆分工作区、建立选中元件的属性面板、统一图表就地导出；保持光路参数与结果快照跨工作区共享。
3. 主操作流程稳定后再优化三维构图、透镜外形、模式缩略图和过渡效果。

## 后续验收任务

- 单透镜案例：首屏可找到透镜焦距，不滚动整页即可改为 80 mm、运行完整计算并定位最小光斑。
- 扫描任务：进入扫描工作区即能看见目标元件、范围和开始入口；零结果、进行中、取消、成功和失败均有说明；返回工作区保留设置与数据。
- 精度识别：能直接辨认输入目标 N 和当前结果实际 N；预览不会被标成完成焦区细化。
- 导出：对光斑、扫描、A/B 和纵向图分别执行“导出此图”，核对导出对象与当前可见图一致。
- 显示：检查 1366×768、100% 缩放与 1920×1080、125% 缩放下的主按钮、焦距、观察面和图例；当前源码最小窗口为 1180×780，需专门处理较矮屏幕。
- 回归：相同输入的新旧版本数值、参数快照、原始数据与警告按现有容差核对；比较 CPU/CUDA、取消和线程退出。当前尚未执行这些改版后的验收。
