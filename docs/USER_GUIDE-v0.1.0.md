# GaussianLab V0.1.0 使用说明

## 便携版运行方式

1. 下载 `GaussianLab-v0.1.0-Windows-x64.zip`。
2. 将 ZIP **完整解压**到可写目录，例如桌面。不要在压缩软件内直接运行。
3. 双击解压文件夹中的 `GaussianLab.exe`，等待界面和首次计算完成。无需安装 Python 或额外科学计算库。
4. `_internal` 文件夹包含运行库，必须与 EXE 保持原有相对位置，不能只拷贝 EXE。

运行环境：64 位 Windows 10/11 与可用的 OpenGL 图形驱动。本版实际验证平台为 Windows 11 x64；未对所有显卡和系统版本作兼容性保证。程序未做商业代码签名；若系统出现安全或权限提示，请按所在单位要求处理。

## 快速演示

- 启动默认显示“单透镜聚焦”，观察三维光束在透镜后收缩和展开。
- 顶部选择“双透镜扩束”后点击“加载案例”，观察两片透镜与光束扩展。
- 选择“光阑衍射”并加载，勾选“对数光斑”，可查看较弱的衍射环。
- 鼠标拖动三维区域旋转、滚轮缩放；“复位视角”恢复默认视角。
- 移动观察屏滑块，联动查看光斑、剖面和轴向曲线。“播放传播”自动移动观察屏，再次点击暂停。
- “强度曲面”以高度表示光强，不代表光束传播轨迹。

## 修改光路与扫描

**“参数扫描”和“扫描数据”为空时：** 顶部“计算光场”只计算当前一组参数，不会自动执行扫描。请在左侧“03 单参数扫描”选择元件、起点、终点和点数，点击“开始扫描”。等待底部显示“扫描完成”后，参数扫描页显示曲线，扫描数据页显示结果表。首次扫描前，V0.1.0 这两页为空；“检查末端 r86 收敛”也不会生成扫描结果。

左侧光路表可修改元件的 z 位置、焦距或孔径数值，并新增透镜或光阑。透镜输入为焦距，光阑输入为直径，单位 mm；光源束腰输入为半径。修改后点击“计算光场”。

扫描区选择某片透镜或某个光阑，设置起点、终点和点数，再点击“开始扫描”。表格和曲线中的最小 r86 是末片透镜后离散采样点中的最小值。扫描页的主场景和指标卡仍保留上次完整光场结果，避免与扫描曲线混淆。

## 保存与导出

“保存项目”保存 JSON，“打开”恢复参数；examples 文件夹附带三个可加载项目。“导出 CSV”输出当前轴向或扫描数据，并保存对应参数快照；扫描额外保存扫描设置。“导出当前曲线”支持 PNG/SVG/PDF；“场景截图”保存三维 PNG。

输出位置可在文件对话框中选择。建议保存在可写文件夹，避免选择系统安装目录。

## 计算口径和局限

模型为单色、同轴、近轴、理想薄透镜及圆孔的标量传播。高斯 w 为强度 1/e² 半径，衍射 r86 为 86% 包围能量半径；两者定义不同。发散角为半角，θ86 与高斯 θ 也须区分。

横向三维显示放大 25 倍，透镜与支座外形为示意；内部亮芯是视觉辅助。有限窗口和网格会影响衍射结果；“末端收敛”仅比较末端 r86，不证明焦区与远场全面收敛。遇到采样、边界或最小点提示时，应调整网格/窗口/传播区间复核。

## 故障反馈

若启动失败，优先确认整个文件夹已完整解压、运行库未被移动、系统与显卡驱动可用。程序会尝试把启动错误保存到 `%LOCALAPPDATA%\GaussianLab\logs\startup-error.txt`。反馈时附版本、操作步骤及错误记录，并先检查是否包含个人路径。

本版使用 Qt/PySide6 等第三方组件，许可和对应源码说明见同目录 `THIRD-PARTY-NOTICES.md` 与 `THIRD_PARTY_LICENSES`。
