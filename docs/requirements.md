# 需求记录

记录日期：2026-11-14。状态：用户原始需求及多透镜、扫描、视觉偏好已记录；计算路线仍在解释与讨论。

## 已确认需求

- R01：课题为“高斯光束经简单光学系统的传输仿真与光斑质量分析软件设计”。
- R02：采用 Python 开发一个高斯光束传输计算器。
- R03：输入透镜焦距、光阑、距离。
- R04：输出束腰位置、远场发散角、聚焦光斑尺寸曲线。
- R05：提供简单的 GUI 界面。
- R06：先寻找 skill，利用工具调研开源软件和代码，记录学习结果，再与用户讨论产品设计。
- R07：每次改动完成后创建对应 Git commit；每次改动编写或更新相关测试，交付前通过测试与验证。
- R08：支持多片薄透镜，并预置单透镜聚焦、双透镜扩束案例。
- R09：包含沿传播距离变化的光斑尺寸曲线，以及随焦距、光阑变化的扫描曲线。
- R10：具有非常好的视觉效果和视觉冲击力，优先采用 3D 展示。用户表示“最好使用3d”，具体渲染与性能方案待验证。

## 建议补充输入（尚未确认）

- 光源：波长 λ、入射束腰半径 w0、束腰相对入口的位置。高级模式可用入口半径 w 与波前曲率 R 替代，避免重复输入互相矛盾的参数。
- 光路：按顺序配置自由空间距离、薄透镜焦距（允许负焦距）、圆形光阑直径；明确光阑轴向位置及透镜有效口径。
- 观察：观察面位置、传播区间；扫描时选择扫描参数、上下限和点数。
- 可选功率：未输入时只显示归一化强度及相对透过率。
- 数值仿真：计算窗口、网格数量和收敛检查设置，普通用户默认折叠。

## 指标与适用边界（建议）

- 第一版限制空气中、单色、同轴、圆对称 TEM00 入射、近轴传播、理想薄透镜与圆形硬光阑。
- 理想高斯模式：w 为强度降至峰值 1/e² 处的半径；同时标明直径 2w。发散角默认半角，单位 mrad，可显示全角 2θ。
- 束腰位置分别标明全局 z 和相对末片透镜的位置；若只存在回推束腰或束腰超出观察区间，需要明确提示。
- “聚焦光斑尺寸曲线”已确认同时包含轴向曲线和焦距、光阑扫描。扫描多透镜系统时需要指定被扫描的元件；光阑扫描分别记录最小光斑、焦点位置和透过率。
- 光阑截断后不再假定严格高斯：显示强度图、剖面、包围能量半径 r86（固定 86%）、透过率，以及数值搜索区间内的最小 r86 位置。
- 衍射模式远场使用包围能量角 θ86，并标明能量百分比；不与高斯 1/e² 半角混用。
- M² 暂不作为首版必需输出。理想硬光阑的衍射尾部会使二阶矩指标对窗口敏感，不能直接将有限网格拟合值标作标准 M²。
