# GaussianLab 下一轮开发计划：从仿真光斑到实验对照

2026-11-20 讨论稿。基线为 V3.1.0 本地 Windows 便携版。以下排期按一人全职估算，验收数字是开发目标。首批使用场景为教学实验和毕业设计中的单透镜聚焦。

**建议交付一个能带进实验室的功能：导入一张有标尺的实测光斑，在相同 z 位置与完整仿真比较，并保存一张可复核的对照图和一份数据表。** V3.1 已有透镜有效口径、仿真 A/B、纵向强度图、白底导出和 CPU/CUDA。当前最有价值的新信息是模型预测与真实记录相差多少。现有功能见[操作指南](USER_GUIDE.md)，分发基线见[本地 EXE 验收记录](release-artifacts-v3.1.0.json)。

## 里程碑与交付

| 顺序与估算 | 交付内容 | 进入下一步的条件 |
| --- | --- | --- |
| ① 样本与基线，2 人日 | 用单透镜案例设计一次对照。取得一份可使用的原始单色数值矩阵、像元标尺、观察面位置与光路参数，尽量同时取得同曝光暗帧。记录 V3.1 在测试机上的改参延迟、导出结果与实际后端。 | 确认矩阵是线性强度计数，弄清单位、图像方向、传感器与物面的倍率。若暂缺真实样本，先做合成数据技术样机，将实测验收留待补样。 |
| ② 文件导入与标定，3 人日 | 新增独立的“实验对照”入口。优先支持有示例的二维数字 CSV；若取得的首批原始文件是灰度 TIFF，则先做该格式。录入物面有效 µm/px、z、坐标方向，可选暗帧和矩形分析区域，预览原图与处理后图。 | 未标定时只报 px。能识别非矩形 CSV、非数值、尺寸不符的暗帧及零信号；彩色渲染截图给出明确提示。加载失败仍可继续查看上次成功的结果。 |
| ③ 同面定量对照，4 人日 | 指定实测 z，在该面取完整仿真。显示两侧光斑、中心剖面、质心及 r86，列出绝对差与相对差。支持按质心对齐比较形状，并保留对齐前的偏移量和坐标依据。 | 合成圆高斯验收通过；改变 z、像元尺寸和感兴趣区域后能追到差异来源。缺少共同坐标原点时只比较形状，缺少功率标定时仅给相对强度。 |
| ④ 复现与便携验收，3 人日 | 白底对照图、指标 CSV、处理参数 JSON。保存输入文件摘要、标定、背景、分析区域、实际 z 与仿真设置。重开记录后可定位原文件，发现文件变化时提示。 | 另一位试用者能用同一输入复现导出的数值。解压后的 EXE 实走文件导入、对比、导出；同时覆盖现有 A/B 和纵图两项新功能。分别记录 CPU、实际 CUDA、断网回退的结果。 |

合计约 **12 人日，可分三周**。样本与设备等待时间另计。首轮只依赖文件交换，不要求实验室开放相机 SDK。实现上复用现有图表、导出和后台任务调度，实测帧单独保存坐标、计数及标定信息，避免把它塞进包含多个 z 面的仿真结果对象。

## 哪些数字可以验收

- **先验算法。** 对无噪声、无饱和、边缘能量可忽略且采样充分的圆高斯，强度满足 `I(r) ∝ exp(−2r²/w²)`，解析半径为 `r86 = w·sqrt(−ln(0.14)/2)`。拟以质心误差 ≤0.5 像素、r86 误差 ≤1 像素为合成用例首轮门槛。在像元尺寸改为两倍的用例中，物理长度也应加倍。
- **再验实验。** 在同一物面、相同分析区域比较。定量比较优先使用原生采样或按实验像元面积积分后的仿真值，图像插值仅用于显示。r86 的圆心统一为所选区域内的能量质心，图中标注该定义，保留现有模拟光轴口径供追溯。百分差以实测半径为分母。逐图单独说明背景算法和负残差处置，记录区域扩大后半径变化。对饱和、裁边、低信噪比给出质量标记，保留原图。真实测量按标定误差与重复拍摄的离散程度解释，合成用例的像素门槛仅用于算法回归。
- **核对平台与响应。** V3.1 本机 N=256、33 面的三轮预览中位数为 CPU 0.544 s、CUDA 0.668 s，包含 400 ms 输入等待。计划在同机同场景重复至少 20 组，记录从末次输入到正确结果的中位数、P95、主界面最长停顿及实际后端。新功能关闭时中位数较同轮 V3.1 恶化超过 10% 就复查；导入和导出期间检查界面响应及旧结果覆盖。在 NVIDIA 笔记本和可取得的无独显实体机各做一次便携试用，缺席设备单列。[原始基线记录 DEV-022](development-log.md)

## 数据或工期变化时怎么取舍

如果第 2 人日仍只有截图或缺少标尺，后续先交付像素单位的合成案例、现有 A/B 与纵图的 EXE 回归、采样警告复核。实测定量对比进入带样本的试用阶段。若用户反馈首要痛点仍是停顿或首次启动，则根据基线优先做 V3.1.x 修复，按任务分开测计算、绘图与 CUDA 初始化耗时。

下一阶段可选两项。其一，在有合适背景和足够采样时增加主次轴二阶矩直径 D4σ，用旋转椭圆高斯与固定版本 laserbeamsize 交叉检查。其二，针对已出现采样警告的短焦距或小孔径案例，用现有 LightPipes 对照及带限角谱实验检查误差随网格变化的趋势。M² 拟在取得多平面标定序列后单独立项；相机直连则以实际设备型号及 SDK 可用性为前提。[既有算法调研](research.md)
