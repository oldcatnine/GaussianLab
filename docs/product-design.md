# 产品设计草案

状态：讨论稿。Python 为用户已确定选择，其余架构与界面是建议方案。

## 产品定位

面向毕业设计演示与定量分析的 Windows 桌面高斯光束传输计算器。让用户配置简单光路，观察聚焦和截断效应，导出可用于论文的曲线及可复现参数。

## 建议实现阶段

1. 解析计算：自由传播、薄透镜、多元件顺序光路；输出束腰、发散角、轴向 w(z)，配套解析基准测试。
2. 桌面 GUI：参数输入、光路列表、曲线、指标卡片、观察面控制、JSON 保存加载与 CSV/PNG 导出。
3. 光阑衍射：圆孔遮罩、场传播、二维光斑及剖面、r86、透过率、θ86，以及解析/数值对照和收敛提示。
4. 对比与交付：焦距/孔径/距离单参数扫描、典型案例、验证报告、Windows 打包。

完整课题的验收应覆盖第 3 阶段；仅有 ABCD 和“光阑警告”不能视作光阑仿真完成。

## 界面布局

```text
┌ 文件：新建 / 打开 / 保存       案例       计算 / 导出 ┐
│ 光源与光路（左侧）       │ 束腰位置 / 最小半径 / 半角 │
│ 波长、束腰、入口位置     │ 光路示意与 ±w(z) 包络     │
│ 距离→透镜→光阑→距离     │ 标签：光斑 / 剖面 / 扫描  │
│ 元件新增、编辑、排序     │ 观察面 z 滑块与精确输入   │
│ 解析/衍射模式、计算设置  │ 指标说明与当前模型边界    │
└ 参数校验 / 计算进度 / 网格收敛状态                 ┘
```

衍射模式中用 r86(z) 替换严格高斯包络标签；保留无光阑解析曲线作为参考。强度图统一显示坐标单位、归一化规则和色标；对比透过率时避免逐图自动归一化掩盖功率损失。

## 计算与数据设计建议

- 技术栈候选：Python 3.12、NumPy、SciPy、PySide6、Matplotlib、pytest；依赖兼容性待验证，衍射引擎待评估。
- 模块：解析光学、数值传播、质量指标、光路模型、GUI、文件导出；计算内核不依赖 GUI。
- 内部使用 m、rad 等 SI 单位，界面显示 nm、mm、μm、mrad。保存文件带 schema 版本、参数单位、算法与采样设置。
- 输入给定入口位置为 z=0、束腰位置为 z_w 时，入口 q=-z_w+i z_R；空气中 z_R=πw0²/λ。自由传播 q'=q+d，薄透镜 1/q'=1/q-1/f。
- 空气中解析发散半角 θ=λ/(πw0)，w(z)=w0 sqrt(1+((z-z_w)/z_R)²)；一般系统使用 q'=(Aq+B)/(Cq+D)。
- 同轴圆孔半径 a 处入射高斯半径 w 的透过率基准为 T=1-exp(-2a²/w²)。多光阑后的非高斯场不能继续套用此式。
- 数值模式焦点定义为指定搜索区间内 r86(z) 最小值；注明步长、边界最小值及是否完成局部细化。
- 强截断衍射远场另算角分布与 θ86；不直接使用高斯 θ 公式。绝对强度仅在输入功率且归一化受验证时显示。
- 长时间衍射和扫描交给工作线程，支持取消；结果携带参数快照，防止参数已改变却显示旧结果。

## 建议首批案例与测试

- 自由传播：在束腰、正负瑞利长度处验证 w=w0 和 sqrt(2)w0。
- 单透镜聚焦：解析 q 变换计算结果与独立参考对照；验证负焦距、虚束腰和超出观察区间的提示。
- 双透镜扩束：与 ABCD 组合基准对照，避免将有限瑞利长度系统一律当作理想准直光。
- 大孔径：数值与无光阑解析结果在收敛精度内接近；小孔径：透过率符合输入面积分，显示衍射环。
- 数值误差：分别加密网格和扩大窗口，验证焦点尺寸、能量和远场指标；阈值由基准实验确定并记录，未收敛时不给“高精度”结论。
- 交互：非法输入、单位转换、配置往返、观察面切换、参数扫描及导出结果一致性。
