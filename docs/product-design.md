# 产品设计草案

状态：讨论稿。Python、多片薄透镜、单透镜聚焦/双透镜扩束预置、轴向及焦距/光阑扫描已确认；用户优先希望采用有视觉冲击力的 3D。计算与渲染架构仍为建议方案。

## 产品定位

面向毕业设计演示与定量分析的 Windows 桌面高斯光束传输计算器。让用户配置简单光路，观察聚焦和截断效应，导出可用于论文的曲线及可复现参数。

## 建议实现阶段

1. 解析计算：自由传播、薄透镜、多元件顺序光路；输出束腰、发散角、轴向 w(z)，配套解析基准测试。
2. 桌面 GUI 与 3D 原型：参数输入、光路列表、三维光束与元件、联动观察屏、曲线、指标卡片、JSON 保存加载与 CSV/PNG 导出。
3. 光阑衍射：圆孔遮罩、场传播、二维光斑及剖面、r86、透过率、θ86，以及解析/数值对照和收敛提示。
4. 对比与交付：焦距/孔径扫描、典型案例、视觉与交互打磨、验证报告、Windows 打包；距离扫描作为可扩展项。

完整课题的验收应覆盖第 3 阶段；仅有 ABCD 和“光阑警告”不能视作光阑仿真完成。

## 界面布局

```text
┌ 文件：新建 / 打开 / 保存       案例       计算 / 导出 ┐
│ 光源与光路（左侧）       │ 束腰位置 / 最小半径 / 半角 │
│ 波长、束腰、入口位置     │ 主视图：3D 光路与光束     │
│ 距离→透镜→光阑→距离     │ 可移动观察屏 + 焦点标记   │
│ 元件新增、编辑、排序     │ 右侧：光斑图 / 强度曲面   │
│ 模式、计算设置、预置     │ 底部：轴向曲线 / 参数扫描 │
└ 参数校验 / 计算进度 / 网格收敛状态                 ┘
```

衍射模式中用 r86(z) 替换严格高斯包络标签；保留无光阑解析曲线作为参考。强度图统一显示坐标单位、归一化规则和色标；对比透过率时避免逐图自动归一化掩盖功率损失。

## 两种计算的直观解释

- 解析计算：将未显著截断的理想高斯光束用 q 参数表示，快速求透镜后的束腰、半径和发散角，适合实时调整焦距和间距。
- 真实光阑衍射：计算入射光场被孔径遮罩截断后如何传播，可观察能量损失、光斑形状变化、衍射环和旁瓣。计算采用标量近轴波动模型，“真实”并不表示完整 Maxwell 求解或包含所有真实镜头像差。
- 例子：同一光路逐渐缩小孔径，解析高斯参考与截断衍射结果并排比较；孔越小透过功率越低，远场可能展宽，不能简单把光束画得更细作为计算结果。

## 3D 视觉方案（建议）

- 整体风格：深色光学实验台、低干扰网格、半透明蓝色透镜、带孔金属光阑、可调色光束、清晰的焦点和距离标注；提供浅色论文导出样式。
- 中央场景：三维光束包络或强度等值面，支持旋转、缩放、侧视、俯视、复位；点击光学元件在参数区定位。
- 观察屏：沿 z 轴移动，实时联动二维光斑、横向剖面、局部半径和轴向曲线游标；允许精确输入位置。
- 强度曲面：以 x、y 为横坐标，以强度 I 为高度，展示高斯峰和衍射环。明确这是强度曲面，不是光束传播轨迹。
- 答辩演示：单透镜聚焦、双透镜扩束一键切换；扫描播放时同步显示当前焦距/孔径、3D 结果和扫描曲线位置。播放缓存的已计算结果，不用动画掩盖未完成计算。
- 比例：光斑通常远小于传播距离，支持横向视觉放大并持续标注倍率；尺寸测量与导出始终使用物理坐标。
- 强度：采用明确色标，可切换线性/对数显示；对数用于观察弱衍射环。装饰性发光与物理强度色标分开，波长伪彩明确标识。
- 物理一致性：透明包络、体渲染与切片从计算数据生成；圆对称场可旋转重建为三维展示，这不意味着进行了完整三维电磁仿真。
- 性能：调整视角不重新求解；预览与高精度结果分级并明确标记，3D 显示可降采样但指标必须由计算网格获得。先验证目标机器渲染与响应，再确定帧率指标。
- 验收：验证 3D 切片与二维光斑数值一致、改变观察面或参数无旧结果混入、单位与放大标注正确，并对预置案例进行截图视觉检查。

## 计算与数据设计建议

- 技术栈候选：Python 3.12、NumPy、SciPy、PySide6、PyVista/VTK、PyVistaQt、Matplotlib、pytest；PyVistaQt 用于嵌入 3D 场景，Matplotlib 承担精确曲线与论文导出。依赖、Windows 显卡渲染与打包兼容性待验证，衍射引擎待评估。
- 模块：解析光学、数值传播、质量指标、光路模型、GUI、文件导出；计算内核不依赖 GUI。
- 内部使用 m、rad 等 SI 单位，界面显示 nm、mm、μm、mrad。保存文件带 schema 版本、参数单位、算法与采样设置。
- 输入给定入口位置为 z=0、束腰位置为 z_w 时，入口 q=-z_w+i z_R；空气中 z_R=πw0²/λ。自由传播 q'=q+d，薄透镜 1/q'=1/q-1/f。
- 空气中解析发散半角 θ=λ/(πw0)，w(z)=w0 sqrt(1+((z-z_w)/z_R)²)；一般系统使用 q'=(Aq+B)/(Cq+D)。
- 同轴圆孔半径 a 处入射高斯半径 w 的透过率基准为 T=1-exp(-2a²/w²)。多光阑后的非高斯场不能继续套用此式。
- 数值模式焦点定义为指定搜索区间内 r86(z) 最小值；注明步长、边界最小值及是否完成局部细化。
- 强截断衍射远场另算角分布与 θ86；不直接使用高斯 θ 公式。绝对强度仅在输入功率且归一化受验证时显示。
- 长时间衍射和扫描交给工作线程，支持取消；结果携带参数快照，防止参数已改变却显示旧结果。

## 建议首批案例与测试

- 自由传播：在束腰、正负瑞利长度处验证 w=w0 和 sqrt(2)w0。
- 单透镜聚焦：解析 q 变换计算结果与独立参考对照；验证负焦距、虚束腰和超出观察区间的提示。
- 双透镜扩束：与 ABCD 组合基准对照，避免将有限瑞利长度系统一律当作理想准直光。
- 大孔径：数值与无光阑解析结果在收敛精度内接近；小孔径：透过率符合输入面积分，显示衍射环。
- 数值误差：分别加密网格和扩大窗口，验证焦点尺寸、能量和远场指标；阈值由基准实验确定并记录，未收敛时不给“高精度”结论。
- 交互：非法输入、单位转换、配置往返、观察面切换、参数扫描及导出结果一致性。
