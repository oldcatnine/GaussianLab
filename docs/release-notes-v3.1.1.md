# GaussianLab V3.1.1 版本说明

V3.1.1 将高精度采样、HG/LG 高阶输入和多模式相干叠加纳入 Windows x64 便携包，同时补齐源码显卡安装入口。

- 完整计算默认网格从 512 提升到 1024，最高支持 2048；轴向最高 641 点，组合仍受 384 MiB 结果体积限制。
- 支持最多 8 项同波长、同轴、共用束腰的 HG/LG 模式，配置阶数、振幅和入口相位；近乎完全相消时明确报错。
- 便携运行包随附固定 CuPy/CUDA 组件；源码可双击 `安装显卡加速.cmd`。安装器使用 UTF-8 读取中文依赖注释，并仅安装固定版本二进制轮子。
- 冻结测试核验默认 1024 网格，以及模式控件到后台计算的相干输入链路；基模包络与实际 r86 指标继续分别标示。

新增 `GAUSSIANLAB_CUDA_HEADERS_WHEEL`：可指定用户自行获取的固定官方轮子，验证摘要后离线初始化；运行包不分发完整头文件轮子。

GPU 需要兼容 NVIDIA 驱动，首次便携 CUDA 需联网补充约 3.6 MB 官方头文件。没有兼容显卡或网络时可使用 CPU。自动预览仍为 256/33，不能用于最终采样精度评价。未重新发布历史 V3.1.0，也未自动上传 GitHub。

操作见 [V3.1.1 指南](USER_GUIDE-v3.1.1.md)，实际附件与冻结验证见 [交付验证](release-validation-v3.1.1.md)。
