# GaussianLab V3.0.0 便携版使用说明

## 启动

目标平台为 Windows 10/11 x64。完整解压 GaussianLab-v3.0.0-Windows-x64.zip，双击 GaussianLab.exe，保留 _internal、docs、examples 和许可目录。无需安装 Python 或完整 CUDA Toolkit；不支持将单个 EXE 复制出去运行。窗口标题和文件属性应为 3.0.0。

V3 随附 CuPy 与应用需要的 CUDA 12.9 运行 DLL，不附带或修改显卡驱动。CUDA 需要兼容的 NVIDIA 显卡和驱动；无显卡、驱动不兼容或初始化失败会回退 CPU。实际后端显示在图下，悬停可看回退原因。

首次 CUDA 会将约 0.72 GB 的随包运行组件放入用户临时目录的 GaussianLab/runtimes，并从官方 PyPI 固定地址下载约 3.6 MB 的配套编译头文件轮子，核对 SHA-256 后在本机缓存。首次需要联网和缓存空间，可能等待数秒或更久；之后缓存有效时无需重复下载。联网失败时使用 CPU。没有把完整 Toolkit、系统驱动或开发环境路径作为运行前提。

如临时目录含中文且 CUDA 初始化失败，可将 GAUSSIANLAB_CUDA_CACHE 设置为有写权限的英文目录后重启；不要求修改系统区域设置。CUDA 路径和原始许可见 THIRD-PARTY-NOTICES.md、THIRD_PARTY_LICENSES/CUDA。首次 CUDA 补充下载来自 NVIDIA 官方轮子在 PyPI 的发布文件，不从其他软件目录复制库。

## 预览与完整结果

默认停止修改数值 400 ms 后自动预览；元件表格按回车或移出单元格提交编辑后更新。预览最多 256 网格、33 个轴向点，不进行焦区细化，图下标为“快速预览”。点击“计算光场”才使用原始网格、轴向点数与细化设置。可关闭自动预览继续手动计算；参数扫描与收敛检查仍手动运行。

后端可选自动、CPU、CUDA 优先。自动模式小网格优先 CPU，完整默认网格通常尝试 CUDA；CUDA 优先也会在预览中尝试显卡。首次编译较慢，不能将它与预热后的性能等同。连续改参会取消旧任务，旧结果不会覆盖新输入；相同设置可复用会话缓存。

## 观察和导出

三维区域滚轮缩放、左键旋转；“复位视角”恢复默认。观察屏滑块、“定位最小光斑”和传播播放用于查看不同 z。三维横向放大 25 倍，元件外形为示意。

右上切换光斑、剖面、强度曲面与包围能量；右下选择六类图像或当前分析图后导出。PNG 300 dpi，另支持 SVG/PDF，均为白底。预览导出带 -preview 默认名与质量标签，CSV 元信息保留实际采样和请求参数；精度判断请使用完整计算与收敛检查。

examples 附带三种项目 JSON。“保存项目”与“打开”处理输入，CSV 导出同时保存参数、指标和元信息。输入改变但结果尚未更新时，旧图仍属于上次快照。

完整操作见 [当前指南](USER_GUIDE.md)，原理与教学练习见 [离线学习手册](项目学习手册.html)。启动错误记录在 LOCALAPPDATA/GaussianLab/logs/startup-error.txt。反馈时请附 Windows/显卡/驱动、实际后端和参数，不只描述“卡顿”。

本版未商业签名。当前仍为单色同轴近轴标量模型；采样警告、硬孔径、小光斑和边界情况需要收敛复核。其他实体电脑和全部驱动组合尚未验证。
