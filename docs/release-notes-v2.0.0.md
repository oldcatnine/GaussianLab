# GaussianLab V2.0.0

本版将已验证的 CPU 数值增强、白色主题与分析图像导出整理为 Windows x64 便携运行包。相对于 V0.1.0，主要增加：

- 焦区局部细化、最低平台括区与边界诊断。
- 横向网格、窗口和轴向采样的多指标收敛检查。
- 包围能量图、结果元数据、参数快照与焦面能量曲线导出。
- 白色界面、三维背景及低强度白色的统一色标。
- 光斑、剖面强度曲线、强度曲面、包围能量、轴向与扫描六类白底图片导出。
- 当前操作指南、离线教学手册、示例和完整第三方许可。

版本号统一为 2.0.0，包含窗口标题、程序元数据、EXE 文件属性与发行文件名。CUDA/自动预览仍保持撤回状态。

## 附件

- GaussianLab-v2.0.0-Windows-x64.zip：其他电脑运行所需的完整便携包，解压后打开 GaussianLab.exe；保留 _internal。
- GaussianLab-v2.0.0-Qt-Corresponding-Source.zip：与随包 Qt/PySide6 相对应的原始源码及摘要清单。
- GaussianLab-v2.0.0-Application-Source.zip：应用源码、依赖快照、打包配置、测试和文档，不含虚拟环境、本机 IDE 与运行输出。
- SHA256SUMS.txt：上述三个 ZIP 的 SHA-256 清单。

目标为 Windows 10/11 x64，无需安装 Python；当前实际验证平台为本机 Windows 11 x64。隔离 Python 路径验证不能替代在另一台实体电脑或所有显卡上的复测。程序未进行商业代码签名。

模型边界仍为单色、同轴、近轴标量、理想薄透镜与圆孔；局部焦点与有限窗口需要收敛复核，不提供任意参数精度保证。V0.1.0 历史附件与记录保持不变。实际构建、解压与冻结程序验证见 release-validation-v2.0.0.md。
