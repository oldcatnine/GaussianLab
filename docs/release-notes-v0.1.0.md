# GaussianLab V0.1.0 — Windows 首个发布版本

这是“高斯光束经简单光学系统的传输仿真与光斑质量分析软件设计”的首个可运行发布版。

## 下载与运行

应用用户下载 **GaussianLab-v0.1.0-Windows-x64.zip**，完整解压后运行 **GaussianLab.exe**，无需 Python。`_internal` 必须保留。不要把 GitHub 自动生成的 Source code ZIP 当作可执行包。

## 功能

- 多片理想薄透镜与圆形光阑的光路编辑。
- 单透镜聚焦、双透镜扩束、光阑衍射预置案例。
- 高斯 ABCD/q 参数参考、二维 Fresnel 衍射、束腰/发散半角/透过率/r86 分析。
- 可旋转 3D 光学实验台、移动观察屏、传播播放、二维光斑、剖面及三维强度曲面。
- 轴向曲线与焦距/光阑扫描，JSON 保存加载、CSV 及图像导出。

## 附件

- `GaussianLab-v0.1.0-Windows-x64.zip`：完整便携运行包，包含 EXE、运行库、使用说明、示例和第三方许可。
- `GaussianLab-v0.1.0-Qt-Corresponding-Source.zip`：对应 Qt/PySide6 第三方源码及下载来源/校验清单，普通运行不需要解压它。
- `SHA256SUMS.txt`：附件校验值。
- GitHub 标签源码：本项目源码、打包配置、测试和开发过程记录。

## 使用边界

采用单色同轴标量近轴模型，有限 FFT 窗口与网格会影响精度，焦点为离散采样搜索。w 与 r86、θ 与 θ86 定义不同；三维横向放大 25 倍。当前不覆盖高 NA、像差、偏振和标准 M²。

未实现透镜独立有效口径、显示状态保存、扫描动画及焦点局部细化；可通过同位置独立光阑表示有限孔径。首版未进行商业代码签名。

源码自动化测试为 37 项通过；冻结 EXE 的隔离 PATH 冒烟测试已经验证三个案例、Qt/VTK 渲染、配置往返、孔径扫描和 CSV，退出码 0。最终 ZIP 解压后的复核结果见仓库 `docs/` 发布记录。

本机目前验证 Windows 11 x64。验证细节、已知环境诊断和后续计划见仓库 `docs/`；“隔离 Python 环境”不等于已在全新操作系统或全部显卡上验证。
