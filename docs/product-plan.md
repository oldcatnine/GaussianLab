# 高斯光束传输与光斑质量分析软件产品设计方案

版本：V1.0（设计汇总稿）

日期：2026-11-14

课题：高斯光束经简单光学系统的传输仿真与光斑质量分析软件设计

开发语言：Python

目标平台：Windows 桌面

当前状态：需求与设计阶段，尚未实现计算内核、GUI 或 3D 场景。

## 1. 产品定位与目标

开发一款兼顾定量计算与直观演示的高斯光束传输计算器。用户通过配置光源、透镜、光阑及传播距离，分析光束如何聚焦、扩束和衍射，并通过交互式 3D 光学实验台观察计算结果。

产品围绕三个目标设计：

1. 算得清楚：提供束腰位置、远场发散角、聚焦光斑尺寸和光阑透过率，并说明指标定义和适用条件。
2. 看得直观：采用具有视觉冲击力的 3D 主场景，联动二维光斑、强度剖面和参数曲线。
3. 便于复现：保存光路与计算配置，导出数据及论文用图，形成可验证的毕业设计成果。

## 3. 典型使用流程

1. 新建项目或加载单透镜聚焦、双透镜扩束案例。
2. 设置波长、初始束腰半径及束腰相对入口的位置。
3. 按光传播顺序新增、编辑、排序透镜、光阑和自由空间段。
4. 运行计算，在 3D 场景中查看光路、束腰和观察屏光斑。
5. 移动观察屏，联动读取当前位置的光斑尺寸、二维强度图和剖面。
6. 指定透镜或光阑，扫描焦距或孔径，分析最小光斑、焦点位置和透过率的变化。
7. 保存项目，导出曲线、数据和场景截图。

## 5. 输入与结果定义

### 5.1 输入约定

- 波长以 nm 显示；元件位置、距离、焦距及孔径以 mm 为主；束腰可用 μm 或 mm；内部统一 SI 单位。
- 光阑输入统一采用直径，计算内核转换为半径；透镜输入焦距，允许正、负焦距，禁止零焦距。
- 每片透镜可设置有效口径；衍射模式将有限口径作为遮罩处理，解析模式显示截断提示。
- 观察区间、观察面位置和扫描范围明确显示；孔径、波长、光斑半径必须为正，离散点数应满足计算要求。
- 同一轴向位置存在多个元件时保留显式顺序，文件保存与界面显示一致。
- 未设置功率时仅显示归一化强度及相对透过率；高级计算设置包括窗口尺寸、网格和收敛配置。

### 5.2 输出口径

| 输出 | 定义与呈现方式 |
| --- | --- |
| 高斯半径 w | 强度降至峰值 1/e² 处的半径，同时可显示直径 2w |
| 束腰位置 | 显示全局坐标及相对末片透镜位置；回推束腰或超出区间时明确提示 |
| 发散角 θ | 默认高斯远场半角，单位 mrad；全角 2θ 单独标注 |
| r86 | 以光斑中心为圆心、包含该面总能量 86% 的半径，用于圆对称衍射光斑 |
| 数值最小光斑 | 指定搜索区间内最小 r86 及其位置；标记边界最小值、采样步长和细化状态 |
| θ86 | 远场包含总能量 86% 的角半径，与高斯 θ 分开展示 |
| 透过率 | 相对指定输入面的功率比；区分单个光阑与整个系统 |
| 扫描曲线 | 明确扫描元件、单位、固定观察面尺寸或重新搜索的最小尺寸；两种口径不可混用 |

首版不把有限窗口下的二阶矩拟合直接标为标准 M²。光阑衍射具有长尾，需先解决窗口敏感性和测量定义问题。

## 6. 物理模型与计算方案

### 6.1 适用范围

首版以空气中、单色、同轴、圆对称 TEM00 入射光束为对象，采用近轴传播、理想薄透镜和圆形硬光阑模型。透镜的三维外观是示意模型，焦距来自输入值，不根据展示厚度计算折射。

高数值孔径矢量聚焦、完整三维电磁求解、偏振、复杂像差、非线性介质和镜片制造误差不纳入首版范围。

### 6.2 解析计算

利用 ABCD 矩阵和复光束参数 q 计算未截断理想高斯光束的传播：

- 瑞利长度：`z_R = πw0² / λ`。
- 入口面为 z=0，束腰位于 z_w 时：`q_in = -z_w + i z_R`。
- 自由传播：`q_out = q_in + d`。
- 薄透镜：`1/q_out = 1/q_in - 1/f`。
- 组合光路：`q_out = (Aq_in + B) / (Cq_in + D)`。
- 光斑半径：`w(z) = w0 sqrt(1 + ((z-z_w)/z_R)²)`。
- 空气中的远场发散半角：`θ = λ / (πw0)`。

解析结果适合实时预览，也为数值算法提供无光阑基准。启用有限口径时，不把解析曲线标为截断后真实结果。

### 6.3 光阑衍射

以二维复振幅描述光场，依次施加光阑遮罩、透镜相位和传播算子，得到观察面的强度分布。优先评估基于 FFT 的 Fresnel 传播及其焦区采样方案，远场通过适用的傅里叶光学模型计算。

“真实光阑衍射”表示显式计算遮挡后的波动传播，可呈现光环和旁瓣；其精度仍受近轴假设、网格、窗口及算法适用条件限制。

必须分别检查加密网格和扩大计算窗口后的结果变化。焦斑尺寸、能量或远场指标未收敛时显示提示，禁止仅因图像平滑而标记计算通过。用于展示的归一化处理不得改变功率统计。

### 6.4 光斑质量分析重点

通过最小光斑尺寸、焦点位置、透过率、包围能量曲线和强度剖面，比较聚焦能力、能量集中程度和衍射旁瓣。展示孔径缩小导致的能量损失与可能的远场展宽，使分析超出单一束腰数值。

## 7. 3D 视觉与交互设计

### 7.1 视觉方向

采用深色光学实验台风格：低干扰网格、半透明蓝色透镜、带孔金属光阑、具有明暗层次的光束、清晰的焦点和距离标签。颜色、透明度及辅助线服务于光路辨识，同时提供浅色论文图样式。

### 7.2 三种核心视图

1. 三维光路：展示透镜、光阑、光束包络或强度等值面，支持旋转、缩放、侧视、俯视和复位。
2. 移动观察屏：沿 z 轴拖动屏幕，联动二维光斑、横向剖面、局部尺寸和轴向曲线游标；支持精确坐标输入。
3. 三维强度曲面：以 x、y 为横坐标、强度为高度，直观看到高斯峰和衍射环，并明确区别于传播轨迹。

### 7.3 动画与演示

- 一键切换单透镜聚焦和双透镜扩束案例，自动选择合适的全局视角。
- 参数扫描完成后播放缓存结果，同步显示当前焦距或孔径、光束、观察屏及扫描曲线位置。
- 支持暂停、逐点查看和恢复初始参数；实时调整采用预览质量，精确计算另行标记。
- 视频文件导出列为可选扩展，首版必需交付为交互演示与静态图片。

### 7.4 科学一致性与性能

- 光束的横向尺度通常远小于光路长度，提供横向视觉放大并持续标明倍率；测量、计算和数据导出始终使用物理尺寸。
- 光束包络、强度等值面和光斑切片由同一份计算数据驱动；圆对称结果可旋转重建，不将其称为完整三维电磁仿真。
- 装饰性发光与物理强度色标分开，伪彩与线性/对数显示模式明确标识；跨参数比较可锁定共同色标。
- 转动相机不触发重新求解。渲染可降采样，数值指标使用计算数据；旧结果与当前参数不一致时明确显示待计算状态。
- 在目标 Windows 机器上验证 Qt、VTK、显卡及打包兼容性后，确定帧率与响应时间验收值；目前不承诺未经实测的性能数字。

## 9. 参数扫描与预置案例

### 9.1 扫描设计

- 焦距扫描：指定一片透镜，扫描其焦距，输出固定面光斑或搜索区间最小光斑、焦点位置及发散指标。
- 光阑扫描：指定一个光阑，扫描直径，输出 r86、焦点位置、系统透过率及适用的远场指标。
- 单次扫描固定其他元件，明确上下限、点数及焦点搜索区间；双参数热图与自动优化留作扩展。
- 允许取消和查看已完成点；失败点保留错误原因，曲线不可用插值静默补成成功结果。
- 扫描结果与逐点独立计算保持一致；改变当前参数不会覆盖已保存的比较结果。

### 9.2 案例设计

| 案例 | 演示重点 | 验证重点 |
| --- | --- | --- |
| 单透镜聚焦 | 光束收缩、束腰及离焦后展宽，联动观察屏 | q 变换、束腰位置和最小尺寸 |
| 双透镜扩束 | 光束通过两片透镜后的尺寸及发散变化 | 矩阵顺序、实际输出尺寸与曲率，避免误用理想准直倍率 |
| 光阑衍射演示（建议补充） | 孔径缩小、能量下降、衍射环及远场展宽 | 入射面透过率、能量统计和收敛 |

案例参数在实现阶段根据解析基准和数值采样条件确定，随项目保存，支持一键恢复。

## 10. 软件架构与技术选型

| 层次 | 建议方案 | 职责 |
| --- | --- | --- |
| 运行环境 | 独立 Python 3.12 环境 | 隔离现有开发环境，锁定依赖 |
| 数值内核 | NumPy、SciPy，自主 ABCD 核心 | 参数转换、传播、指标和扫描 |
| 衍射引擎 | 优先评估 LightPipes 或自主实现 | 以基准与采样验证结果决定最终依赖 |
| 桌面界面 | PySide6 | 光路编辑、状态与交互 |
| 三维展示 | PyVista/VTK、PyVistaQt | 场景、切片、强度曲面及相机 |
| 二维图表 | Matplotlib | 定量曲线、光斑图与论文导出 |
| 测试与打包 | pytest；评估 PyInstaller | 自动化验证及 Windows 分发 |

计算内核不依赖 GUI。工作线程接收不可变参数快照，计算结束后携带任务编号与配置标识返回；界面只接收对应当前任务的结果。数值求解、显示降采样与相机刷新分别管理，支持取消计算。

## 11. 数据保存与导出

项目 JSON 至少包含 schema 版本、软件/算法版本、光源、元件顺序和参数、单位、观察区间、扫描设置、网格及窗口设置；显示参数单独存储。

扫描 CSV 包含元件标识、扫描参数、指标名称、单位、计算状态和误差说明。二维图可导出 PNG、SVG、PDF，3D 场景导出 PNG；图片包含坐标、色标、尺寸口径和必要图注。大规模复场数据默认不写入项目 JSON，结果重算或独立存储。

上述方案为已有调研与设计判断，尚未完成依赖兼容性、数值对照和打包实测。复制代码时保留对应版权、许可与必要声明，发布时整理第三方依赖清单。完整证据与 Skill 查找记录见 [开源与 Skill 调研](research.md)。

## 14. 测试与验收标准

| 验证类别 | 验收内容 |
| --- | --- |
| 解析正确性 | 束腰处 w=w0，正负瑞利长度处 w=sqrt(2)w0；自由传播、透镜与组合矩阵对照 |
| 光阑与衍射 | 圆孔入射高斯透过率 T=1-exp(-2a²/w²) 对照；无光阑数值结果趋近解析解；无损传播功率统计 |
| 数值收敛 | 分别改变网格和窗口，检验光斑、能量、焦点和远场；阈值经基准标定后固定并记录 |
| 参数扫描 | 与相同参数的逐点独立计算一致，错误点、取消和边界最小值正确处理 |
| 数据与交互 | 单位转换、负焦距、非法值、保存加载往返、任务切换与旧结果隔离 |
| 3D 一致性 | 切片与二维图一致，横向放大标识正确，视角变化不改变物理数值 |
| 视觉质量 | 两个预置案例与衍射场景截图检查；文字清晰、标签无遮挡、色标一致、焦点和衍射环可辨识 |
| 性能与分发 | 记录测试硬件、场景、网格和耗时；验证交互响应、取消以及 Windows 打包后启动 |

每次改动编写或更新相关测试，交付前通过相应验证并创建 Git commit。当前文档测试只证明设计记录完整，不能代替未来的物理、GUI、性能和视觉验收。

## 15. 风险与处理

| 风险 | 处理方式 |
| --- | --- |
| 焦区采样不足或窗口截断导致假结果 | 解析基准、局部采样评估、网格和窗口双向收敛 |
| 3D 显卡或 Qt/VTK 打包兼容性 | P0 提前验证目标机器；保留二维分析视图并明确 3D 不可用状态 |
| 强视觉效果掩盖真实尺寸与能量 | 放大倍率、色标、归一化与模型范围持续可见 |
| 衍射及扫描耗时导致卡顿 | 工作线程、取消、缓存、预览与精确结果分级 |
| 指标混用造成结论错误 | 区分 w 与 r86、θ 与 θ86，以及固定面尺寸与最小尺寸 |
| 功能范围不断扩张 | 首版聚焦理想同轴系统；像差、偏振、优化和视频导出独立列为扩展 |
