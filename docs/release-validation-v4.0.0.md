## 下载与验证方法

单连接下载较慢，先检查官方端点返回 HTTP 206 与准确 Content-Range，再使用 24 路、2 MiB 分段下载。每段验证范围、长度，合并后重新核对完整 SHA-256；下载失败重试保留 TLS 验证。顺序下载的部分文件不作为通过证据。网络状态查询出现过 TLS EOF，重试后成功，未修改代理或关闭证书校验。

本机分发目录为 releases/v4.0.0，包含三个 ZIP、校验清单和实际下载解压的运行目录；测试副本位于 outputs。历史 V3.x 与更早发行不覆盖。GitHub 仓库维持本次开始时的现有可见性，不调整访问权限。

## 版本管理与边界

后续每次应用小更新补丁号增加 0.0.1：4.0.0 → 4.0.1 → 4.0.2。同一发行的验证证据补录不改变已发布程序或摘要。本页及证据提交是发布后记录；标签和随包文档保留构建时状态。

当前结果属于软件、数值与冻结发行验证，没有新增实体光学实验或跨设备兼容性结论。V3.2 工作台规划继续作为设计提案阅读。
